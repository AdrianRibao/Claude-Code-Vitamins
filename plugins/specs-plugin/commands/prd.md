# /prd Command

Invoke the prd-writer skill to generate Product Requirements Documents.

## Usage

```
/prd [feature-name] [--type master|feature|api|integration] [--no-questions] [--ask] [--review] [--consolidate @path]
```

## Arguments

$ARGUMENTS

## Instructions

Run the `prd-writer` skill with the provided arguments. Pass all arguments exactly as received.
