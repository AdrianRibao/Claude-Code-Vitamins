# /tdd Command

Invoke the tdd-writer skill to generate Technical Design Documents.

## Usage

```
/tdd [feature-name] [--type backend|ui|api|integration] [--prd @path] [--iterative] [--ask] [--review] [--consolidate @path]
```

## Arguments

$ARGUMENTS

## Instructions

Run the `tdd-writer` skill with the provided arguments. Pass all arguments exactly as received.
