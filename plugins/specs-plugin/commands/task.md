# /task Command

Invoke the task-writer skill to capture backlog tasks, maintain the board, and optionally drive a task to shipped.

## Usage

```
/task [name] [--ticket ID] [--page URL] [--from @path] [--do NNN|@path] [--branch NAME] [--no-branch] [--ask] [--review @path] [--reformat @path|--all] [--board] [--consolidate @path] [--ship NNN|@path]
```

## Arguments

$ARGUMENTS

## Instructions

Run the `task-writer` skill with the provided arguments. Pass all arguments exactly as received.
