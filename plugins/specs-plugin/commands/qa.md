# /qa Command

Invoke the qa-runner skill to run a spec's QA plan in a real browser with agent-browser and record the evidence.

## Usage

```
/qa @spec-path [--env local|staging] [--only QA-N,...] [--no-exploratory] [--review]
```

## Arguments

$ARGUMENTS

## Instructions

Run the `qa-runner` skill with the provided arguments. Pass all arguments exactly as received.
