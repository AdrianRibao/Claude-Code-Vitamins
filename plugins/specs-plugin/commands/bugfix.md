# /bugfix Command

Invoke the bugfix-writer skill to generate bugfix specifications and optionally drive the fix.

## Usage

```
/bugfix [name] [--ticket ID] [--page URL] [--from @path] [--fix] [--ask] [--review @path] [--consolidate @path]
```

## Arguments

$ARGUMENTS

## Instructions

Run the `bugfix-writer` skill with the provided arguments. Pass all arguments exactly as received.
