Shipped work, kept out of [the board](../BACKLOG.md) but not out of reach.

These files are the reason a decision was made, not just a record that it was. Several of them explain why something is deliberately *not* the obvious way — read the relevant one before re-litigating a choice it already settled.

## Conventions

- **The ID never changes.** `001` here is the same `001` that was on the board.
- **Add a row when you archive a file**, and say what the task *settled* — not what it did. The commit history already records what it did; what a future reader needs is which questions are closed.
- **Nothing is deleted.** If a shipped decision is later reversed, the reversal gets its own task and this entry stays, so the trail runs both ways.
